# Applied AI Engineering Atlas — backbone v0.2

The repaired, validated backbone for the atlas map, plus one deep-dive research guide per region.

## Contents

| File | What it is |
|---|---|
| `backbone.yaml` | Source of truth. Regions, boundary rules, 141 nodes, 190 lineage edges. Edit this. |
| `backbone.json` | Same data as JSON, generated by `validate.py`. Feed this to the map. |
| `validate.py` | Mechanical checks: ids resolve, relationship enum, child-not-older-than-parent, cycles, region counts, missing sources. Writes `backbone.json` and `validation-report.txt`. |
| `validation-report.txt` | Current result: 0 errors, 0 warnings. |
| `make_guides.py` | Generates the deep-dive guides from the backbone. Re-run after any backbone change. |
| `deep-dives/` | One research guide per applied region (prompt + seed sources + cross-region edges). |

## Shape of the graph

- 8 root disciplines (pre-LLM ancestors) and 11 applied regions; every applied region has 8–12 anchors.
- 79 of 190 edges cross regions — these are the land bridges.
- 15 `external:` ancestors mark real lineage that isn't anchored yet (e.g., `external:elo-rating`, `external:minhash`). They're candidates for the next revision, not errors.
- Node `status`: 8 kept from Gemini as-is, 76 repaired, 57 added.

## What changed from the Gemini run (v0.1 → v0.2)

**Structure**
- New root region **Software Engineering and Operations** (statecharts, TDD, distributed tracing, LSP) — the honest ancestor of workflows, evals, tracing, and MCP.
- Real nodes in the **HCI** root (conversational agents, direct manipulation, mixed-initiative interaction) so the Product region descends from HCI rather than from decoding internals.
- Security root expanded (least privilege, injection attacks); RL root gains PPO; deep-learning root gains pretrained LMs, fine-tuning, distillation, MoE, SSMs.
- New relationship type **`counters`** for attack/defense pairs (injection defenses → prompt injection), which didn't fit the original five.
- Parents may be `external:<name>` when the true ancestor isn't anchored — this replaces forced nearest-node edges.
- Agent sandboxing moved from Agents to Safety; boundary rules updated to match.

**Edges re-parented** (examples)
- `function-calling` now descends from Toolformer-style tool learning and MRKL (→ expert systems), not only structured outputs.
- `react-agent-loop` from chain-of-thought + MRKL (function calling post-dates it).
- `llm-tracing` from distributed tracing; `eval-driven-development` from TDD; `model-context-protocol` from function calling + LSP.
- `rlvr` from RLHF + PPO, dated 2024-11 (Tülu 3 coined it); `grpo` from PPO, dated 2024-02 (DeepSeekMath).
- Prompting nodes no longer all hang off `zero-shot-prompting`; `context-engineering` (2025) combines compaction, system prompts, and RAG.

**Regions topped up**: Data 3→8, Product 4→8, Safety 4→12, Eval 5→9, Multimodal 3→9.

**Added coverage**: prompt injection (direct and indirect), jailbreaks, interpretability and SAEs, model cards, MRKL, Toolformer, constrained decoding, local inference, distillation, MoE, SSMs, copilots, chat interfaces, canvases, CLIP, ASR, diffusion, text-to-image, video, deep research agents, agent skills, LLM+P, scratchpads, self-reflection, agent benchmarks, RAG evals, online evals.

**Removed**: `context-aware-mcp` (unverified 2026 paper padding for recency), `cot-pass-at-k` (too narrow for a backbone), `verifiable-reasoning-traces` (vague; folded into RLVR). These appear as leads in the relevant deep-dive guides.

**References fixed**: KV-cache quantization now cites KIVI (not SmoothQuant); KV cache cites Shazeer 2019; test-time compute cites Snell et al. 2024; agentic RAG cites the Singh et al. survey; sandboxing cites Goldberg et al. 1996. All 24 empty edge sources filled.

**Maturity recalibrated**: DPO, LoRA, PEFT, RLHF down from 5 to 4; GraphRAG 3→2; speculative decoding and MCP 3→4.

## Known limits

- arXiv ids come from model knowledge; 8 were spot-checked against arXiv (all correct). Expect a few errors in the rest — the deep dives will surface them.
- 15 edges are marked `confidence: medium`; they're the most debatable lineage claims and worth a look.
- Dates mark when a technique appeared, sometimes the paper and sometimes the first product. That's fine for layout, but don't present them as precise.

## Workflow for deep dives

1. Run a guide's prompt in a deep-research tool.
2. Give the output to a Claude agent: parse Section 2 into YAML, merge into `backbone.yaml`, run `validate.py`.
3. Review Section 3 (amendments) by hand before accepting structural changes.
4. Re-run `make_guides.py` so later guides see the updated ids.
